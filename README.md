## 常见问题

**机场和 VPN 有什么区别？**

机场提供订阅链接，在 Clash、Shadowrocket 等客户端里导入后可以按规则分流：国内网站直连，国外网站走代理。传统 VPN 一般全局转发所有流量。机场节点多、价格低，但需要自己装客户端。

**哪个机场最便宜？**

按官网价格，折合每月最便宜的是 无忧链接（¥6.58/月）、唯兔云（¥6.66/月）、飞猫云（¥7/月），基本都是年付小流量套餐。价格以官网为准。

**这些机场有免费试用吗？**
